# Fevzi Tugrul Varna, PhD

**Lead AI Engineer and Observability Architect**  
Visiting Research Fellow in Informatics, [University of Sussex](https://profiles.sussex.ac.uk/p391890-fevzi-tugrul-varna) · Co-founder, [SwarmLab](https://swarmlab.co.uk/)

I build C# and .NET systems for warehouse operations and business workflows. A question that guides my work is: when one service reports success but the next never completes its task, what evidence would let an engineer explain why?

## Software engineering

- **Observability for distributed systems.** I lead development of a platform that brings together logs, metrics and traces from warehouse management software, material flow controllers and RabbitMQ. I use OpenTelemetry and Grafana to help engineers follow an operation across application boundaries.
- **AI-assisted root cause analysis.** I design investigations that give a model incident telemetry and a map of application dependencies. I evaluate whether the evidence supports each finding, what the model missed, and how much time and cost the investigation required.
- **Business workflow automation.** I built .NET services for invoice intake, supplier verification and document extraction, with dashboards that let operators review the results.

My day-to-day stack includes ASP.NET Core, EF Core, SQL, RabbitMQ and Azure. My deployment work spans Azure Container Apps, Kubernetes and OpenShift.
